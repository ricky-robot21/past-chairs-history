# How to add a chair to the History Timeline

For the History and Archives committee. About two minutes for a basic entry.

## Add a chair

1. In the WordPress menu, click **History Entries**, then **Add History Entry**.
2. Type the chair's name in the **Add title** box.
3. **Type** is already set to **Chair**. Leave it.
4. Type the **Start year** (four digits), such as `2026`.
5. Type the **End year** if the term ran more than a year, such as `2027`. Leave it blank for a single year.
6. Type the chair's **City**, such as `Austin`. This is optional.
7. Type a **Short summary**, one or two sentences. This is required.
8. Click **Publish**. Publishing can take about ten seconds. Wait for the green "Post published" message.

The chair now shows on the History page in the right decade. You do not choose the decade.

## Add more to a chair

All of this is optional. A chair with any of it gets a **Read more** button.

- **Photo:** use the **Photo** box on the right, then **Set photo**. Pick a picture at least 400 pixels wide. The timeline cuts it to a tall rectangle, so put faces in the middle. The pop-up shows the whole picture. Open the picture in the media library and fill in **Alt text**, a short description for people who cannot see it. The edit screen warns you if the alt text is missing or the picture is too small.
- **Full story:** type it in the large text box at the bottom of the page.
- **Video:** paste a YouTube link into **YouTube link**.
- **Video transcript:** if you add a video, paste what is said in it into **Video transcript**. People who cannot hear the video can read it. The edit screen reminds you if it is missing.
- **PDFs:** click **Add File** under **PDF 1**, and type the link text under **PDF 1 label**, such as `1994 Annual Report`. You can add up to three.

## Fix, hide, or reorder

- **Change something:** open the chair from **History Entries**, edit, and click **Update**.
- **Hide a chair without deleting:** change **Status** to **Draft**, then **Update**.
- **Two chairs in the same year:** use the **Order** number on the right. Lower numbers come first.
- **A chair who served in separate years**, such as 2013 and 2015: type `2013, 2015` in **Other years**. Searching either year finds the chair.
- **Special wording for the years**, such as `2019 to 2020 (co-chairs)`: type it in **Date label**.

## Add many at once

Go to **History Entries**, then **Import**. Download the template, fill in one row per chair, and save it as CSV. Click **Preview** first, check the result, then choose the file again and click **Import now**.

## Add a milestone

Same steps, but choose **Milestone** for **Type**. Use the **Start year** as the year it happened and leave **End year** blank.

## If something looks wrong

- **The chair is missing from the page:** check the Status is **Published** and that a Start year is filled in.
- **The page looks old after an edit:** refresh the browser once.
- Anything else: send the chair's name and a screenshot to the web team.
